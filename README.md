## About

I'm a Creative Technologist and Founder of **Design Matrix**, working at the intersection of real-time 3D, XR, and AI. I design and build immersive digital experiences — from Unreal Engine environments and interactive applications to AI-assisted creative and development workflows.

- 🎮 Building real-time 3D worlds and interactive experiences in **Unreal Engine 5** and **Unity**
- 🥽 Developing **VR/AR** applications and interactive training tools
- 🤖 Integrating **AI** into creative and software development workflows
- 🎬 Producing 3D animation, motion graphics, and visual design
- 🚀 Currently building **Design Matrix** — a creative technology studio combining software, AI, and 3D
